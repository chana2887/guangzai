# 光崽第一版体验与验收标准

2026 年 11 月 22 日确认。实现顺序、接口约定和三组交付清单见[软件实施计划](../plans/2026-11-22-guangzai-v1.md)。

## 实物使用体验

我从左边伸手，光崽就向左看。它可能想起我们上次玩过，问「今天还玩吗？」我用左、右键切换「一起玩」和「晚点吧」，用中键确认。光崽先接上相应动作，再显示一句短话。它没有提问时，同样用左、右键选活动，中键执行。

一起玩完，光崽会记下这件事，下次在合适的对话里提起。选「晚点吧」时，光崽回应这一次，并继续待机。称呼、明确偏好和自由聊天可以在控制台打字，装置旁的日常养成和简短对话可以全程用红外和按钮完成。

我在忙时，光崽大多数时候自己待着，偶尔做点小动作，也偶尔主动问一句。没人回答时，气泡自动收起。平时多摸摸它，它以后会更常凑近。经常陪它玩，它会更爱蹦跳。临时困倦或专注时，它可以安静一点。

长大后，光崽逐步学会新动作和主动发起的新活动，同时解锁自己的小场景和装饰。场景与服装分开选，可以自由搭配或换回默认。重开后保留上一次搭配。小场景以台灯、书本这类道具表现，投影里的角色和气泡共享校准后的反射画面。

## 第一版验收

| 编号 | 验收内容 | 通过条件 |
| --- | --- | --- |
| V1 | 实物互动与对话 | 左、右红外各触发一次，角色看向对应方向。平时菜单和对话都用左、右键切换，中键确认。从装置正常观看位置能读清短句和当前选项，确认后看到对应动作和回复。全程不用键盘。 |
| V2 | 互动记忆与显式记忆 | 完成一次玩耍，重启后，在相关对话中能看到光崽提到「上次一起玩」。确认「晚点吧」的独立测试中，光崽只回应当下。通过键盘告诉它「以后叫我小王」，后续打招呼能用上这个称呼。 |
| V3 | 待机与性格 | 演示节奏下，从干净的待机状态起算，一分钟内看到一次自发小动作，三分钟内看到一次主动搭话。放着不答，气泡自动收起并回到待机。比较成长阶段与临时状态相同的两种养成记录，可观察到常摸头的一份更常凑近，常玩耍的一份更常蹦跳。日常节奏可以比演示更稀疏。 |
| V4 | 成长与自选装饰 | 对比成长前后，能看到新动作，例如看过来后挥手，也能看到成长后新学会的主动邀请，例如问「要不要一起自习？」至少解锁一个小场景和一件装饰。用实体键分别切换两者、恢复默认，重启后仍显示上次选好的搭配。 |

软件组负责从输入、对话、记忆和成长状态到投影表现的完整串联。动画组负责角色动作及适配装饰的素材，硬件组负责按键、红外、转台和屏幕的实际输入与输出。软件可先用临时企鹅和模拟输入验收逻辑，最终 V1 和 V4 需要在组装后的装置上按表验证。
