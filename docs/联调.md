# 光崽动画与硬件联调

## 动画组交付

动画放到 `public/animations/`。推荐 H.264 MP4、纯黑背景、静音、24 或 30 fps。角色居中，头脚周围留边，各片段保持相同视角、尺寸和构图。可用 960×540 出第一批，按实物分辨率调整。每个文件名仅用英文字母、数字、短横线或下划线，也接受 WebM。

把文件名填到同目录的 `manifest.json`，刷新网页即可。例如：

```json
{
  "clips": {
    "idle": "idle.mp4",
    "pat": "pat.mp4",
    "feed": "feed.mp4",
    "play": "play.mp4",
    "sleep": "sleep.mp4",
    "focus": "focus.mp4",
    "look-left": "look-left.mp4",
    "look-right": "look-right.mp4"
  }
}
```

| 状态 | 播放建议 |
| --- | --- |
| `idle` | 必备，待机循环 |
| `sleep`、`focus`、`bored`、`think` | 可循环 |
| `look-left`、`look-right`、通用 `look` | 手势后约 1.8 秒，短动作 |
| `wave-left`、`wave-right`、通用 `wave` | 幼崽起转头后播放，约 2.2 秒。起始姿势衔接同方向的转头片段 |
| `pat` / `feed` / `play` | 分别约 1.8 / 2.8 / 3.2 秒 |
| `happy` / `sad` | 分别约 1.8 / 2.1 秒，对话反馈 |
| `idle_glance`、`idle_lean`、`idle_hop` | 回望、凑近、蹦跳，各约 2.2 秒，从待机姿态出发再接回待机 |
| `sleep_shift`、`focus_stretch` | 睡觉挪身约 3.2 秒，自习伸展约 2.6 秒，各自接回原循环 |

只收到 `idle` 也能先接入。验收正式角色的 V3 动作时，需要在清单中同时配置相应的短片。缺片时播放可用的睡眠、自习或待机循环。没有可用循环时显示临时企鹅。调整反射画面使用控制台的「画面校准」，可设水平或垂直镜像、旋转、大小和偏移，同一浏览器的投影窗口会同步设置。

V4 书房图可以在清单的 `scenes.study` 填写透明 PNG/WebP 文件名。道具靠画面两侧，给中央角色和下方气泡留空。围巾穿戴版本在 `outfits.scarf` 中按同名动作填写视频文件名，例如 `idle`、`look-left`、`wave-left` 和 `play`。穿戴片段缺失时用基础片段，清单中没有可播放视频时由临时企鹅显示围巾。书房图缺失时使用占位台灯和书堆。

## 屏幕与树莓派

1. 用 Raspberry Pi OS 桌面先确认屏幕能显示系统桌面，屏幕走 HDMI 或 DSI 由实物型号决定。
2. 将项目复制到树莓派，在项目目录执行 `bash kiosk.sh`。默认打开 Chromium 净屏，可用 `GUANGZAI_VIEW=console bash kiosk.sh` 直接打开控制台。
3. 用 G 回控制台，先静止调板角和画面，再调转动姿态。双屏时可分别打开 `/` 和 `/?projection=1`，将净屏窗口移到反射屏。两窗口必须使用同一地址和端口。

播放器及存档服务只绑定本机回环地址。换端口时，Windows 用 `python server.py --port 8782 --open`，树莓派启动脚本用 `PORT=8782 bash kiosk.sh`。树莓派用设备时区统计每日记录。全屏启动方式可对照 [Raspberry Pi 官方 kiosk 指南](https://www.raspberrypi.com/tutorials/how-to-use-a-raspberry-pi-in-kiosk-mode/)。

## ESP32 和转台

固件入口是 `firmware/guangzai_ir/guangzai_ir.ino`。示例板为经典 ESP32 Dev Module，使用 Arduino-ESP32 3.x 的 LEDC PWM 接口。

| 信号 | 示例接线 |
| --- | --- |
| 左红外数字输出 DO | ESP32 GPIO32，默认低电平表示检测到 |
| 右红外数字输出 DO | ESP32 GPIO33，默认低电平表示检测到 |
| 舵机信号 | ESP32 GPIO18 |
| 舵机供电 | 按实际舵机铭牌用独立电源，电源地与 ESP32 共地 |
| 树莓派与 ESP32 | 使用能传数据的 USB 线 |

接线前先确认红外模块输出与 ESP32 的 3.3 V GPIO 兼容。输出高电平超出规格时先做电平转换。舵机由转盘结构传动，转盘轴承承重。第一次让舵机空载回中，对好舵盘，再测左右。固件的示例 PWM 为 1300 / 1500 / 1700 μs，软件限制在 1200–1800 μs。角度以实物校准为准，方向反了可交换 `leftUs` 与 `rightUs`。固件上电会回中，运行时将两边设为固定预设位。连续遮挡、双侧检测和空白保持当时的目标位。启动和转向后有稳定期，下一次触发前要清空感应区。留足屏幕线和电源线余量，验证舵盘和转台无卡点。 [Espressif PWM 文档](https://docs.espressif.com/projects/arduino-esp32/en/latest/api/ledc.html)

Windows：

```powershell
python -m pip install pyserial
python -m serial.tools.list_ports -v
python server.py --serial COM3 --open
```

树莓派：

```bash
sudo apt install python3-serial
ls -l /dev/serial/by-id/
GUANGZAI_SERIAL=/dev/serial/by-id/实际设备名 bash kiosk.sh
```

如果系统使用 `dialout` 管理串口而当前用户没有权限，由设备维护者将该用户加入串口组后重新登录。Arduino 串口监视器和光崽服务轮流打开该端口。现有设备路径不可用时界面会等待固件心跳并自动重连。

## 串口约定

USB 串口为 115200、8N1，ESP32 每约 200 ms 发一行 ASCII，状态变化时也发。以 LF 结尾，CRLF 也可。

```text
GZ1,0,N,C
GZ1,1,L,L
GZ1,1,N,L
GZ1,1,B,L
GZ1,2,R,R
```

- 第二字段是接受的手势序号，32 位无符号数。同一个手势的心跳持续使用同一个序号。
- 第三字段是消抖后的检测区，`N` 无目标，`L` 左，`R` 右，`B` 双侧。
- 第四字段是舵机目标预设，`C` 中、`L` 左、`R` 右。界面显示目标值，实物完成角度需要观察确认。
- ESP32 完成防抖、重触发限制与舵机控制。树莓派收数据，播放动作，记录交互。同一序号被多个窗口读取时只记一次。

验收时先观察空载左右、双侧与无手的输出，再装轻载检验屏幕线、反射完整性和舵机抖动。最后拔插 USB 验证软件回到等待状态并能重连。
